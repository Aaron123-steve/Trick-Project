# AI 性格测试整蛊页

这是一个静态单页网页，直接打开 `index.html` 就能运行。

## 本地预览

PowerShell 里执行：

```powershell
python -m http.server 8080
```

然后访问：

`http://localhost:8080`

## 分享给别人（部署）

### 方案 1：GitHub Pages

1. 新建 GitHub 仓库并上传 `index.html`
2. 进入仓库 `Settings` -> `Pages`
3. `Build and deployment` 选择 `Deploy from a branch`
4. 分支选 `main`，目录选 `/ (root)`，保存
5. 等 1-3 分钟后会得到公开链接

### 方案 2：Vercel

1. 打开 [https://vercel.com](https://vercel.com)
2. 导入你的 GitHub 仓库
3. Framework 选 `Other`（保持默认也可以）
4. 点击 Deploy
5. 部署完成后拿到公开链接
